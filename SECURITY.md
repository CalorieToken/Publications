# Security and privacy reports

For a suspected vulnerability, exposed personal data or sensitive publication error, contact **info@calorietoken.net** through a private message with the affected public URL and a brief non-sensitive description. Ask for an appropriate channel before sending detailed sensitive evidence.

Do not place credentials, wallet secrets, personal records or exploit details in a public issue. Do not test against other users' accounts or data. This contact route does not create a bug-bounty programme, authorise intrusive testing or promise a response deadline.
